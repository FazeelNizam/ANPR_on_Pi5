## What is this?
This project uses **computer vision** to detect vehicles and extract their **license plate numbers** in real time.

By leveraging the **Raspberry Pi 5**, we achieve faster processing speeds and higher accuracy than previous Pi models.

### Ideal use cases
- 🚧 Smart Parking Systems  
- 🏠 Automated Gate Openers  
- 📹 Traffic Monitoring  
- 🎓 AI / Computer Vision Learning  

---

## ⚡ Why Raspberry Pi 5?
The Raspberry Pi 5 is a versatile compute module, often upgraded for computer vision tasks using low-cost HATs. This setup provides a major performance boost, enabling:
- 📹 Smooth live video streaming
- 🚀 Faster image processing
- ⚡ Quick OCR (Optical Character Recognition)
